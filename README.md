# 🌸 Iris Flower Classification (CodeAlpha Internship Task 1)

This project is part of my **Data Science Internship at CodeAlpha**.  
It uses the famous **Iris dataset** to classify flowers into **Setosa, Versicolor, and Virginica** using machine learning.  

## 🔹 Features
- Data preprocessing and visualization (Seaborn, Matplotlib)
- Logistic Regression model
- Accuracy evaluation with confusion matrix
- Interactive **Streamlit web app**
